# 现代阅读界面设计规则

本套稿沿用已确认的首页、书库与 TTU 阅读设置。目标逻辑尺寸为手机390 ×844、平板834 ×1194、桌面1440 ×1024。实际生成 PNG 尺寸单独记录，不把图像生成结果视为精确排版尺寸。

## 层级与材质

内容区使用稳定底面，封面和正文优先。玻璃集中在导航与临时操作层，设置浮层必须有足够底色覆盖率。主要阅读操作每屏一处；书单、无痕阅读与管理动作保留在更多菜单。分组先靠字号、留白和对齐表达，必要时加细分割线。

| 用途 | 深色目标 | 浅色目标 |
|---|---|---|
| 页面底色 | #09121E | #F4F7FB |
| 控件与浮层 | #142538 | 接近白色的稳定底板 |
| 主要文字 | #EDF4FB | #13283E |
| 强调色 | #70D9FF | #00638D |

阅读纸张主题独立于应用主题。白、纸色、淡蓝、深灰、深色和纯黑样本保留真实颜色；Komga 的三种阅读主题另列，不与 TTU 控件混用。

## 布局与排版

- 页面主标题24–28，分组18，正文与控件标签14–16，辅助信息12–13。UI 使用无衬线，阅读正文可使用宋体类字体。
- 手机内容边距约20，内部节奏12–16。封面按2:3完整展示，网格标题顶部对齐，详情长标题允许换行。
- 触控目标至少48，桌面指针目标至少40；图标通常20–22。不能以缩小点击区解决视觉密度。
- 只有首页、书库、本地、搜索、设置显示五项全局底栏。详情和阅读使用返回栈，宽屏切换为侧栏。
- 按原图归一化后，平板侧栏92、列表260，桌面侧栏237、书目栏422；桌面详情边距40、阅读条边距30。选择与滚动状态在窗口变化时保留。

## 能力与状态边界

筛选即时生效，完成仅关闭；目录展开与选章是不同操作；返回先关闭最上层浮层，再退出阅读。下载、缓存、已读、不可用状态来自现有数据，设计稿的示例数字不作真实数据。字体、阅读模式和主题沿用现有存储值。

视觉稿不代表实际渲染、手势、读屏、性能或阅读位置验收。实现时还需检查英文、简体中文、大字号、减少透明效果和小屏换行。

实现阶段的精确尺寸、测量口径和允许的数据差异见[对齐标尺](MEASUREMENTS.md)。
