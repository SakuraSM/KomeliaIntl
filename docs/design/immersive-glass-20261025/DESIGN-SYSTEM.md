# 沉浸式磨砂玻璃设计规则

本规则配合[页面视觉稿](README.md)使用。用户已选择深色沉浸式方向，并明确要求作品背景只用于有对应内容的区域。当前稿件已完成背景范围修正，应用已按该方向更新，运行证据与未覆盖项见[实现检查报告](../../../design-qa.md)。图片负责表达构图、材质和层级，真实业务字段、状态与权限仍以当前代码和服务契约为准。

## 视觉层级

1. 作品封面与阅读内容是主体。首页和详情页可使用较大作品画面，书库与搜索页必须保留有效浏览密度。
2. 导航、工具栏与少量关键操作位于独立的磨砂层。玻璃需要看得出背景模糊、透光、边缘高光和轻微离地阴影。
3. 表单、长文本和管理列表使用中性深色实面。设置、账号和管理页的背景不放书籍场景或环境插画，不能靠模糊、调暗来保留错误的全局壁纸。
4. 一个玻璃容器内的选中态使用普通填色、文字或图标，不能再嵌套一块独立玻璃。

这些层级参考 Apple 的 [Materials 指南](https://developer.apple.com/design/human-interface-guidelines/materials)。生成图只表达静态目标，不代表已实现苹果原生材质或动态光学行为。

## 基础样式

下表是实现的初始取值，需在实际窗口与设备上按视觉稿校准。

| 项目 | 初始方向 |
|---|---|
| 页面底色 | 墨蓝 `#0D131C` |
| 表单与阅读内容底色 | 接近不透明的深蓝灰，保证文字对比度 |
| 主文字 | 浅白 `#F4F7FC` |
| 次文字 | 灰蓝 `#ADB8C9`，不能靠降低透明度而变得难读 |
| 主操作与选中态 | 天蓝 `#69C9FF` |
| 状态 | 成功用绿色，失败用红色，同时保留文字或图标 |
| 字体 | 界面使用清晰的系统无衬线字体；EPUB 正文字体由阅读偏好与出版物控制 |
| 正文与次要标签 | 以 14 至 16 的逻辑字号为起点，支持系统字号放大 |
| 交互尺寸 | 移动触控区域至少 48dp，桌面指针目标至少 40dp，遵循仓库质量规则 |
| 内容间距 | 优先用 8、16、24 的间距建立分组，再使用分割线 |
| 玻璃形状 | 工具栏、导航栏采用圆角连续的单层容器；圆形按钮仅用于独立操作 |

玻璃的模糊半径、底色透明度、边缘亮度和阴影是运行时参数。不能把生成图上的高光纹理直接贴到控件，也不能把整张生成图作为应用背景。

## 导航与窗口

- 手机主导航按视觉稿使用首页、书库、本地、搜索、设置。目的地对应现有路由，保留返回栈、页面状态和阅读进度。
- 底部导航浮在内容之上，列表仍需预留足够的底部安全空间。最后一行和关键操作必须可以完整滚动到导航栏上方。
- 独立阅读器、登录与专注编辑场景使用对应的工具栏或返回操作，避免机械套用五项导航。
- 桌面使用侧栏和完整表单。Web Komf 使用自己的配置导航，不增加阅读应用的底部导航。
- 生成图中的单行文字、图标大小和栏宽不是固定像素约束。实际布局应覆盖项目测试矩阵中的窄屏、平板和宽屏。

## 内容与示例素材

- 雨夜书店、海岛、列车是作品内容的示例素材，不是 Komelia 的全局品牌背景。真实封面、标题和元数据由书库提供。
- 大图只允许在首页“继续阅读”的明确作品区域或对应作品详情区域中出现。下方列表、说明和页面边缘回到中性底色。
- 书库、搜索、本地内容、合集和阅读列表使用中性深色底，作品图片保留在封面卡片或缩略图中。
- 登录、设置、账号、服务器与 Komf 管理页使用纯深灰或墨蓝背景，不放书籍插画、街景、灯光散景或虚构反射。密度预览、下载任务和通知模板中的实际封面缩略图可以保留。
- 阅读器仅显示出版物页面和阅读背景。色彩校正只在明确的预览框中显示待校正图片。
- 玻璃只采样它下方的真实内容。下方是中性背景时，玻璃保持中性烟灰或蓝灰，不能添加不存在的橙蓝灯光来制造透光效果。
- 示例账号使用保留域名。图中版本、连接成功、任务进度、文件大小、日期、字数与公告均不构成真实数据或运行证据。
- 不把示例字数、章节描述、装饰性阅读预览或额外说明误做成新的业务字段。实际显示文案使用同步的英文和简体中文资源。
- 生成的图标与封面小字可能存在细节差异。实现时使用项目统一图标与真实文字，不能把生成的文字图块当成控件。

## 阅读器边界

- 图片、PDF 和 EPUB 的正文保持清晰，材质只用于阅读控件。不能给原始页面、正文 CSS 或图片处理结果加玻璃滤镜。
- 控件显示时避开正文重点区域，并遵循安全区、自动隐藏和无障碍时限。图中的可见控件状态不代表始终显示。
- 保留翻页、章节顺序、小数章节、缩放、目录、书签、离线来源与进度保存行为。
- EPUB 的主题与边距独立于应用外观；修改应用材质不能重新加载或重写出版物内容。

## 实现与验证边界

保持现有主题、语言、材质和减少透明效果的持久化兼容。继续提供实色回退，不因新的视觉稿移除低性能设备或无障碍路径。

原移动搜索存在实色布局回退。新稿表达其目标视觉，不能据此删除回退或宣称新的玻璃实现已满足帧率要求。需要重新取得目标设备上的滚动与输入证据后再决定材质策略。

动态折射、背景采样、滚动帧率、减少动态、透明度回退、键盘焦点、Back 和 Esc、菜单点击穿透、英中文长文本与窗口变化均未由本轮静态图验证。后续按[测试选择](../../harness/testing-guide.md)执行应用代码变更的检查，并保留截图对照。

## 本轮核对

- 38 张独立页面稿映射到 39 个现有 Screen 入口，代码入口见 [manifest.json](manifest.json)。
- 首页去掉了玻璃容器内重复的玻璃按钮；合集补齐了更多菜单图标；EPUB 章节标注与进度保持一致；公告去掉了多出的搜索控件并恢复返回导航。
- 背景范围修正版更新了全部 38 张页面稿，清除全局街景和虚构反光，保留内容区域中的图片；移除了 EPUB 设置页的装饰性手机插画，并收紧离线登录页的空白。修正提示词与旧图校验值见 [background-correction.json](background-correction.json)。
- 所有图稿均通过本地图片解码检查。图稿覆盖、文件校验与链接检查属于文档验证，不计为应用运行测试。
