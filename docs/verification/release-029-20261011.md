日期：2026-10-11。此次包含 Android 当前页分享、连续阅读视口更新修复及 Komga EPUB 章节边界接续改进。按新增功能的版本规则，从 0.28.1 升为 0.29.0，Android versionCode 从 56 升为 57。

- APK 大小：53,859,325 字节。

使用正式签名、R8 压缩和资源裁剪构建，通过 SDK 工具检查包名、版本、签名及调试标记。模拟器实际安装 APK 的摘要与上述附件一致。

签名配置不加入 Git；原作者漫画、设备截图、应用备份和测试辅助文件也不加入 Git。发布仅上传 APK 和校验文件。

## 正式包运行验证

环境为专用 `Komelia_Regression_API37` 模拟器，1080×2400、密度 420、英文界面。所有输入固定到此模拟器，没有操作 OPPO 手机上的正式版或重启手机。

| 场景 | 实际结果 |
|---|---|
| 正式版 0.28.1 → 0.29.0 覆盖升级 | `install -r` 成功，签名兼容，未清空数据；专用本地文件夹和漫画第 3/4 页、75% 进度保留 |
| CBZ 当前页分享 | 升级后仍显示合成漫画第 3 页，点击分享打开系统 `Sharing image` 面板；取消后能返回阅读与详情，没有发送 |
| PDF 当前页分享 | 合成 PDF 第 2/4 页打开系统分享面板，取消后正常返回，没有发送 |
| 原作者连续长图 | Lanczos3 放大、Mitchell 缩小，连续从上到下、0% 侧边距；快速跳页后静置 40 秒，再做 18 次往返快滑，停手 20 秒和 40 秒文字及线条清晰 |
| Komga EPUB 慢拖接续 | 合成短章进入长章，长章顶部反向慢拖回到短章，再次慢拖进入长章 |
| Komga EPUB 快滑 | 以实际系统快滑穿过长章，进入第 3 章；不通过内部切章方法代替触摸 |

长图为此前 OPPO 验证的同一份原始 CBZ，SHA-256 为 `d9ed6368fa608bf11b5eb17bc9da45142cd3f5416bbd0f19fa61de50b6126ed3`。模拟器保留原有关闭裁边设置，OPPO 此前使用原有开启裁边设置，两组环境分别记录，不将其混称完全相同配置。

此前 OPPO PKJ110、Android 16 上的验证使用含本次应用修复的 `0.28.1-debug` 候选包：三轮原始长图重放均清晰，第三轮静置约 110 秒仍清晰，详见 [视口请求竞态修复与 OPPO 回归](issue-62-oppo-fix-20261011.md)。不能把该测试包的真机结果写成正式 0.29.0 APK 已在 OPPO 上验收。
