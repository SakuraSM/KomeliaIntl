# 阅读体验 v2 组件规范

2026-10-29 确认方向：现有深色磨玻璃为主，冷白作对照，布局更紧凑，强调精确对齐、蓝青色和细高光。正文、书名与封面保持清楚。

这套页面是待确认的视觉方案。本轮应用代码只修复模式与方向提示的持久化，不替换整体页面布局。PNG 由同一套 HTML/CSS 组件在浏览器中按目标尺寸渲染。封面和材质参考使用内置 ImageGen；界面文字与尺寸使用真实排版，避免生成图中文字和比例漂移。

## 颜色与材质

| Token | 深色主稿 | 冷白对照 |
|---|---|---|
| 页面底色 | `#09121E` | `#EEF3F8` |
| 实面回退 | `#132234` | `#F8FBFE` |
| 玻璃底色 | `rgba(28,48,69,.74)` | `rgba(242,248,255,.80)` |
| 主文字 | `#EEF5FF` | `#13283E` |
| 次文字 | `#B8C8DC` | `#465D74` |
| 强调色 | `#70D9FF` | `#00638D` |
| 主按钮 | `#85E4FF` 至 `#56C7F1`，深色文字 | `#05709B` 至 `#005F87`，白色文字 |
| 分割线 | 蓝灰白色，17% 透明度 | 深蓝灰色，17% 透明度 |

导航、重点续读区域和浮层保留明显的磨玻璃。玻璃采用冷色半透明底、细高光边缘和柔和背景采样；正文列表不逐行加模糊，不叠多层卡片。科技感来自准确的网格和细节，避免霓虹、粒子、装饰性仪表和无意义的数据。

预览采用 24px 背景模糊和 125% 饱和度表达材质。这些是视觉目标，Compose 实现继续复用现有材质与滚动采样预算，不能直接据此宣称性能改善。OLED 与降低透明度继续沿用现有选项，内容采用实面回退。

普通文字对比度目标至少 4.5:1，大文字至少 3:1。颜色检查针对已知背景组合；动态玻璃仍需在真实背景上复核。图片不作为原生读屏、帧率或手势验收。

## 页面与操作层级

- 主导航保留首页、书库、本地、搜索、设置。选中态同时通过图标、文字和背景标识。
- 首页先呈现续读，再呈现最近阅读。当前作品保留完整小封面，主操作与进度各出现一次。已有首页分组继续保留在后续实现中。
- 书籍与丛书详情隐藏手机全局底栏。书籍详情只有一个固定阅读操作区。丛书页只在紧凑头部保留一个“继续第12册”。
- 丛书卷册页首屏显示六条示例卷册。排序、筛选、显示方式合并在一个工具行；分页保留在列表末尾，批量管理沿用已有更多菜单或选择态。
- 详情优先显示书名、作者、完整封面和所属系列。文件与来源收起。下载和书单为次操作。
- 本地页分别展示可离线阅读、下载任务和不可用文件。暂停、重试和移除操作按现有任务能力接入，预览不访问真实文件。
- 搜索复用结果行。空查询沿用现有目录浏览行为，预览输入框只筛选设计示例；不新增推荐或搜索历史。
- 设置先呈现文字阅读、漫画/PDF、外观，再呈现文件与离线、账号与高级管理。
- 平板和桌面采用目录与详情并列。桌面保留侧栏，阅读主操作只在右侧详情出现一次。

## 配套状态

| 状态 | 展示规则 |
|---|---|
| 未读 | 开始阅读，不显示虚构进度 |
| 阅读中且进度已知 | 一个进度值，进度条来自同一数据 |
| 阅读中但进度未知 | 仅显示阅读中，不绘制任意进度 |
| 已读完 | 明确标识，允许重读，保留真实最近阅读记录 |
| 无封面 | 中性排版占位，保留正常标题和行高 |
| 不可用 | 一处状态说明；不能伪装为可读内容 |
| 下载中 | 明确显示下载进度，与阅读进度分开，不编造速度或剩余时间 |
| 保存失败 | 保留已保存值并反馈错误，不显示成功状态 |

筛选、EPUB 目录、文字阅读设置和漫画/PDF 设置各有独立配套稿。章节展开与跳转是两个独立操作。文字书的字号与排版选项不出现在固定版式 PDF 或漫画中。

示例书名、作者、封面与进度都是设计数据。丛书对应 Series，书单对应 ReadList，合集保持原有独立语义。评级、销量、社交、阅读时长统计和 AI 不在本轮范围内。

## 模式与方向提示

默认开启，仅首次使用或有效模式、方向变化时提示。同一配置跨书籍、会话和应用重启不重复。关闭开关后全部停用；重新开启后，下次进入阅读或实际配置变化再提示一次。

图片阅读设置页与阅读浮层共用提示开关，保存 `readerModeHintsEnabled` 和 `lastReaderModeHintSignature`。签名使用模式与方向枚举，不包含书籍、语言或会话标识。关闭当前通知不等于关闭所有后续提示。

## 交互与验证边界

实现时返回应恢复来源的筛选、搜索和滚动位置；浮层关闭后恢复入口焦点。菜单、开关与主要操作支持键盘、触摸及读屏。过渡遵循系统减少动态效果设置。

预览支持页面跳转、筛选选中态、搜索示例过滤、目录展开、设置开关和 Escape 关闭浮层。未接入的管理动作会明确提示预览边界，不假装保存到服务器。原生宽度、字号、安全区与交互结果见[UI 对齐验证](../../verification/reading-experience-ui-20261029.md)，读屏与性能须独立验证。

固定色组合的对比度检查覆盖深浅主文字、次文字、强调色和主按钮，最低为冷白主按钮的 5.53:1。该值不包含任意变化的图片背景，玻璃上的文字仍需在应用实现后逐场景检查。
