# 页面与交互对应

| 页面 | 主要任务与交互 |
|---|---|
| 01 首页 | 从唯一主按钮续读；封面和书名进详情；自定义分组从顶部进入，书库范围在书库页选择。 |
| 02 书库 | 搜索、状态、排序、视图集中在一层；点封面进入内容，长按多选；返回保留列表位置。 |
| 03 丛书 | 书籍与合集共用工具栏；读取目标不受当前筛选、分页影响；缺失卷册与已缓存副本保持真实可用性。 |
| 04 文字详情 | 目录和下载为次操作，阅读条固定；书单和无痕阅读进入更多；简介可展开。 |
| 05 漫画详情 | 相邻话与当前页数可见；到达边界时明确提示；不虚构不存在的下一话。 |
| 06 本地下载 | 来源、排序与搜索共用筛选入口；本地目录为行式入口；暂停、重试和取消沿用任务状态。 |
| 07 搜索 | 保留查询和结果类型；点结果进入对应书籍或丛书；清空恢复浏览。 |
| 08 设置 | 阅读、文件离线、书库账号分组；右侧摘要与箭头表达当前值和进入关系。 |
| 09 筛选 | 常用条件前置，高级条件折叠；即时生效；完成固定可达并只关闭面板。 |
| 10 目录 | 当前章高亮；选章保留锚点和既有阅读协议。Komga的真实嵌套目录支持独立展开，TTU沿用其主章节列表。 |
| 11 TTU设置 | 字体摘要一行；六主题与新增入口保留；模式直接调整，其余排版进入更多。 |
| 12 图片设置 | 单页、双页、连续等宽；分镜仅能力可用时出现；方向、提示与音量键开关沿用现有状态。 |
| 13–14 浅色 | 与深色保持相同任务和信息层级，正文和未选按钮不混入深色底。 |
| 15–16 宽屏 | 列表与详情并排，侧栏导航；阅读器独立于详情窗格；返回和缩放保留选择与列表状态。 |
| 17 Komga设置 | 字号、点按翻页、三主题、滚动分页、列数、行距和边距按现有模型分组。 |
| 18 纯阅读 | 点按中心唤起控件；收起后正文优先，纸张主题独立；系统沉浸开关沿用用户设置。 |

长标题、空结果、加载、失败重试、离线和不可用状态仍需保留，本套主稿不把所有状态堆进同一画面。
